# Security

Report suspected vulnerabilities to `security@intentproof.io` or open a
private [GitHub Security Advisory](https://github.com/IntentProof/intentproof-tools/security/advisories/new)
on this repository.

Include affected component, impact, and reproduction steps when safe to share.

Do not post exploit details on public issues.

This is an OSS project without a paid security SLA. Maintainers aim to
acknowledge reports within a few business days.
